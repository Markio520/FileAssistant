```powershell
git clone https://github.com/Markio520/FileAssistant.git
cd FileAssistant
. .\scripts\initialize-dotnet.ps1
dotnet --version
.\scripts\test.ps1
.\scripts\build.ps1
.\scripts\run.ps1 -Unpackaged
```

若另一台电脑已有检出，确认该处没有未处理的改动后执行 `git pull --ff-only origin main`。本次源文件均在仓库内，不依赖旧机器的绝对源码路径。
