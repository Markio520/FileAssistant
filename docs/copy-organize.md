# 复制与整理

2026-11-03（Asia/Shanghai）：用户确认实施首版复制及评审补充。移动、按日期分类和按数量分组尚未纳入本次实现。

## 使用

1. 进入“复制与整理”，添加文件或磁盘文件夹，也可从暂存区导入。
2. 选择或填写目标目录，选择目录模式及同名策略。输入、选择或规则变化后，活动页以 400 ms 防抖自动扫描计划；刷新按钮可重新检查磁盘状态。
3. 计划展示待处理、待确认、跳过和不可处理数量。选择一项查看完整来源、目标路径和原因。覆盖冲突逐项选择编号、跳过或确认覆盖，全部待确认项处理完毕后才能开始。
4. 点击“开始复制”。任务与参数区显示按字节计算的进度、当前文件、完成项数和平均复制速度；内容校验阶段有独立文字提示。开始后使用计划快照，其他输入交互不会改变运行中的任务。
5. 在本次结果或任务明细查看成功、跳过和未完成项。查看输出沿用打开、定位、复制路径和显式加入暂存区；原输入继续保留。

有勾选时展开所选软件文件夹和文件，无勾选时使用当前软件文件夹及子树。筛选保留隐藏项勾选，显示“已选/当前可见”；“清除全部勾选”才切换为当前子树范围。真实磁盘文件夹在计划阶段扫描，软件文件夹仍只管理引用。

## 目录与冲突

| 规则 | 行为 |
| --- | --- |
| 保留结构，默认 | 按最外层已选磁盘目录保留自身名称与层级，包括空目录；单独添加的文件直接放入目标。磁盘根目录使用带“根目录”后缀的名称。 |
| 全部平铺 | 仅复制文件，直接放入目标。 |
| 按扩展名 | 仅复制文件，扩展名统一大写作为子目录，无扩展名进入“无扩展名”。 |
| 自动编号，默认 | 检查磁盘已有项目与本批预留路径；不同来源同名根目录整体编号，文件生成 `名称 (1).扩展名`。 |
| 跳过同名 | 明确记录跳过，不判断内容相同，不计为失败。保留结构时同名目录可合并，文件逐项遵循策略。 |
| 覆盖前逐项确认 | 同名目录可合并，已有文件逐项确认并保留备份。本批重复目标及目录占用不能直接覆盖，提供编号或跳过。 |

按规范路径及 Windows 卷/文件标识去重，包含硬链接别名；源与目标为同一个文件时跳过。本批其他源文件受到保护，不能被复制输出替换。目标在待复制目录内部或与该目录相同，整份计划拒绝并提示调整目标。

首版不跟随目录链接或其他重解析点，包括路径上层的重解析点；扫描列出不可处理原因。云端占位文件可能同样受此限制，请先使用普通本地文件路径。长路径与中文路径已加入测试；单个名称超长或编号后超过限制会列出原因。

执行时目标新增、目标内容变化或提交时名称被占用，都再次执行冲突规则。编号变化记录在实际结果与输出路径中；确认策略的新冲突记为待确认，其他可用项目继续处理，之后通过“重新检查未完成项”进入逐项确认并继续。

## 执行、取消与重试

- Infrastructure 后台调用 Windows `CopyFile2`，回调在进入 UI 队列前合并到约 100 ms，首个数据块和最终状态仍发送。零字节文件和仅目录任务使用项数兜底。
- 源文件执行期间持有禁止写入/删除的读句柄，预览后的长度、修改时间和文件身份变化会拒绝执行。
- 在最终目录写入本任务独有的 `.fileassistant-copy-*.tmp`，完成后比较源与临时文件主数据流的长度和 SHA-256，再提交最终路径。完整校验会增加磁盘读取时间；属性与其他数据流由 Windows 复制能力处理，不承诺复制原安全 ACL。
- 新文件提交使用不覆盖的移动；覆盖通过持有目标句柄校验并改名为备份，再提交新文件，防止文件在校验与备份之间被写入或替换。恢复清单先于替换写入。
- 取消保留已经提交的文件，仅清理未提交临时文件。取消恰好在提交后到达时，该文件仍记成功。清理失败保留具体临时路径和原因，不能伪装成成功。
- 占用、失效和权限问题逐项记录；磁盘满及目标设备/网络断开停止剩余项。不会提升权限或删除源文件来处理错误。
- “重新检查未完成项”仅包含失败、取消、未开始及待确认项；不重做成功或主动跳过项。重新检查生成可审阅计划，仍须点击开始。它沿用原任务的目录与规则，不把后来添加的输入纳入重试。
- 任务和输出历史仍仅本次运行有效，未实现跨重启继续复制或字节断点续传。退出时请求取消并等待正在进行的复制/扫描/恢复，再关闭程序。

## 覆盖恢复

恢复入口位于复制设置的“覆盖恢复”折叠区，重启后可刷新读取。

- 清单：`%LOCALAPPDATA%\FileAssistant\CopyRecovery\{id}.json`，通过临时文件、持久刷新和替换写入。
- 原目标备份：原目标目录内 `.fileassistant-backup-{id}.bak`，与目标同卷；不随清空输出记录删除，不自动过期。
- 恢复检查当前目标是否仍匹配本次复制的内容；用户后来改动目标时拒绝覆盖，备份继续保留。目标缺失时可恢复原文件；替换或恢复中断后可根据预写清单重新检查。
- “删除所选备份”弹窗明确确认，只删除对应且内容未变化的备份，保留当前目标。设备不可用或恢复未完成时拒绝清理。
- 不要直接移走、改名或编辑备份及清单；记录损坏会提示错误，原文件继续保留供检查。
