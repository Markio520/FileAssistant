# 搜索与筛选：第一阶段

2026-10-30 最新确认：用户接受 Everything 后台运行，要求打开本软件即自动启动，不另装或手动启动 Everything。现已随应用分发官方 1.4.1.1032 x64 便携版，使用由应用管理的独立配置和索引。低成熟度开源替代引擎未引入。

## Direction contract

- THESIS：以紧凑结果列表承接输入即查，再把确定的文件收集到操作批次。
- OWN-WORLD：继承现有 WinUI Fluent 控件、冷灰工作面、青色强调和浅深主题；沿用系统字体，不新增位图。
- STORY：选择范围 → 输入和筛选 → 核对路径与信息 → 加入批次。范围、来源、已加载数量与异常始终可见。
- FIRST VIEWPORT：顶部标题与批次入口，第二行范围和搜索框，第三行常用条件，中央 40 DIP 列表和可收起的信息栏，底部计数、加载更多、加入批次。窄窗口保留搜索、结果和主操作，表格允许横向滚动。
- FORM：采用已向用户提供并获实施授权的结构，沿用现有视觉系统；Operate，code-led，无额外概念选择。原生控件反馈，异步结果更新不播放装饰动画。
- FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 实现边界

- Everything 使用官方 QUERY2W IPC，固定分发 1.4.1.1032 x64，原文件签名和发布校验值在构建时验证；运行前再次核对固定 EXE 校验值。无需 SDK DLL，不连接用户自己的默认或 1.5a 实例。
- `EverythingRuntime` 管理每用户独立实例，配置与数据库位于 `%LOCALAPPDATA%\FileAssistant\Search\Everything-1.4`。应用打开时预热；查询取消不会终止建索引，准备期间显示状态，失败后只有显式重试才重新请求权限。
- 首次启动由临时提权进程把已校验引擎写入受保护的 `%ProgramFiles%\FileAssistant\SearchEngine\1.4.1.1032`，安装专用命名辅助服务。主应用不提权；服务不指向可由普通用户替换的开发目录。辅助服务保留并随系统启动，负责磁盘访问；占用索引内存的普通搜索进程随应用窗口关闭退出并保存数据库。
- 自动纳入可用的本机 NTFS 磁盘；首次启动时其他已就绪的本地固定/可移动磁盘加入目录索引。锁定、离线、权限受限目录不承诺完整覆盖；网络位置未自动纳入。非 NTFS 速度和覆盖未做实机验收。
- 不修改用户自己安装的 Everything。命名实例、服务、通信管道和数据库隔离；同用户重复启动应用只激活已有窗口。应用异常退出后可重新接管经路径验证的自有后台实例，引擎崩溃后下次查询重启。
- 指定目录采用显式快照，刷新重新扫描；不跟随目录联接与符号链接。不可访问项计数，取消不显示完整结果。
- 每批 200 条；索引端或快照的完整结果排序后取页。全选仅限已载入项。关键词变化清除当前结果选择，已加入的批次保持独立。
- 最新纠正：搜索页默认显示“所有类型”的当前范围文件；清空查询或筛选后恢复全部结果，仍每次加载 200 项。指定目录未填路径时等待选择，选定后无需关键词即显示内容；切回全盘重新查询并丢弃晚到的目录响应。后台索引预热仍随应用启动，筛选下方的引擎说明行已删除。此行为取代下方历史验证记录中的全盘空白初始状态。
- 类型菜单按参考图提供所有、音频、压缩文件、文档、可执行文件、文件夹、图片、视频，另保留原有仅文件。可执行文件包含 exe、msi、com、bat、cmd，使用与目录/批次一致的扩展名规则生成索引表达式，不把同名扩展名的文件夹当作可执行文件。
- 搜索范围、类型、大小、日期和排序统一使用公共 `SelectionDropDown`，工作区类型及同名文件处理也复用。按钮内容原位保留、菜单下方水平居中，选中项显示主题色竖条及浅色背景，没有圆点或黑色焦点框。外部重置与菜单选择通过稳定的选项值双向同步；方向键浏览，回车/空格或点击确认，Esc 取消。业务选项放在功能模块，控件行为、外观和颜色分别归 `Controls`、`SelectionControls.xaml`、`ThemePalette.xaml`。表头与各列内容保持左对齐，纵向居中。
- 四个表头分隔处使用原生 Thumb，可拖动调整名称、所在位置、大小、修改时间列，也可聚焦后用左右方向键按 8 DIP 调整。表头、当前行和后续加载行共用同一列宽状态，列总宽超过可见区域时横向滚动。本次运行内切换页面保留用户列宽，尚未跨应用重启持久化。
- 右键未选中行先将该行设为唯一选择；右键已选中行保留当前多选。菜单包含打开文件/文件夹、打开所在文件夹、复制完整路径、复制文件名、加入操作批次。打开及定位限单选，复制及加入批次作用于菜单打开时选中的全部项；空白区域不出现文件操作菜单。单个结果也可双击或按 Enter 打开。
- 系统打开、资源管理器定位和剪贴板写入经 Core `IFileInteraction` 交给 Infrastructure 的 Windows 实现，页面不拼接终端命令。项目已移动、删除或无法访问时反馈在搜索页，不把系统异常传播为应用崩溃。
- 输入防抖 150 ms，中文输入法组合期间暂缓查询；新条件取消旧查询，过期结果不会覆盖新结果。Ctrl+F 聚焦搜索，F5/回车刷新，结果列表中的 Ctrl+A 选择已载入项，输入框中的 Ctrl+A 只选文字。
- 结果不会在空闲时自动重新查询；文件变化后刷新获取最新状态。批次仅保存在本次运行内存中，按完整路径忽略大小写去重。
- 大小采用 1024 进制；文件夹及索引中未提供的信息不伪造为 0。
- 基础语法在三个来源共用：空格 AND、`|` OR、`!` 排除、引号、`*`/`?`、`ext:`、`size:`、`dm:today/7days/yyyy-MM-dd`、`file:`、`folder:`；不支持的函数明确报错。

## 使用方式

1. 打开软件即自动准备索引，首次允许 Windows 管理员授权即可。进入“搜索与筛选”的“全部已索引位置”直接查找；无需打开 Everything 窗口。拒绝授权或准备失败时可重试，也可选择目录搜索；不提供外部下载前置。
2. “指定目录”可粘贴路径或选择文件夹，选定后无需关键词即显示内容，不依赖 Everything。是否递归由“包含子目录”控制。输入关键词可继续筛选，清空关键词返回目录内容。
3. 输入 `产品 主图 ext:png;jpg`、`size:>100mb`、`dm:7days !备份` 等条件；上方类型、大小、日期条件会与整条表达式共同约束结果。
4. 用 Ctrl/Shift 多选，或在列表内 Ctrl+A，点击“加入操作批次”。“加载更多”每次读取下一页，全选不会暗中把尚未载入的结果也加入。
5. 打开“操作批次”核对收集的文件。加入批次不执行复制，复制及内容预览仍为后续功能。
6. 拖动表头分隔线调整列宽；右键文件或文件夹执行常用操作。复制路径/名称支持多选，一行一项。
