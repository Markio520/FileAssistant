# 软件内文件夹与输入引用

2026-10-31：用户确认方案并授权实施。软件文件夹用于整理引用；原件保留在磁盘原位置。暂存区、转换、复制输入共用界面和规则，后续输入类功能直接复用。搜索页保持原有结果列表；输出区保持任务列表，两处转交时均可选择目标软件文件夹。

## 使用

- 工具栏“新建文件夹”在当前位置建立分组；双击或单选后 Enter 进入，面包屑与上一级按钮导航，Backspace 返回上一级。
- 文件夹可嵌套，名称最长 120 字符；同级重名新建/转交自动编号，重命名冲突明确提示。空白处右键提供新建和添加；选中项提供移动、添加到其他文件夹、用于功能和移除，单个软件文件夹增加打开和重命名。解散、检查状态收在“更多”。
- 输入列表单击整行选择，Shift 连续选择，Ctrl 增减选择，Ctrl+A 全选当前可见项。选择和拖动由 ListView 原生交互统一处理，行内容不再单独设置 `CanDrag`，避免截走列表选择手势；文件夹双击接收已处理事件，并在当前选择事件结束后导航。
- 外部拖入、选择或粘贴文件追加到当前分组；拖到软件文件夹行加入该组。同一输入列表内部拖拽移动引用；不同输入之间复制引用。拖动来源使用 `DragItemsStarting.Items`，不在拖动开始时重新清空或改写选择；有效目标行高亮，拖动提示显示目标名称和动作。软件文件夹不能移动到自身或子树，放下时再次检查；原生手势验收边界见下文。
- 单组内按完整路径去重，不同分组可引用同一文件。磁盘文件夹本身仍是独立引用，不因软件分组而自动扫描其内容；类型列区分“软件文件夹”和真实文件类型。
- “用于功能”或右键转交使用公共“快捷加入”窗口：默认显示来源数量、目标完整路径和“加入 N 项”，“更改”展开目录树，新建文件夹时才展开名称框；只有源包含软件文件夹时才显示“保留文件夹结构”。仅选空文件夹且取消保留结构时不能提交空导入。原处和目标分别维护，加入后等待用户操作。
- “从暂存区导入”在同一窗口选择来源和目标，单击整行选择、双击软件文件夹进入，不设行内进入按钮。勾选跨目录保留，可全选本层或清除全部选择；进入文件夹浏览时撤掉该文件夹整体的勾选，避免浏览动作把整组误加入。展示选择项数和展开去重后的实际文件数量。保留结构选项使用固定高度的位置，显隐不能改变列表的屏幕位置，双击的导航等行选择事件处理结束后执行。目录选择器中新建是即时操作，主窗口取消加入仍保留新组，可在目标列表撤销新建。
- 移出文件只移除所选成员关系；“解散”把内容移到上一级；“移除文件夹及内容”明确确认范围，移除软件记录并保留磁盘原件与其他功能中的引用。
- “清空”作用于当前分组及子分组的文件引用，保留结构，点击前确认范围和文件数量。
- 每个输入独立提供一次撤销，可恢复最近一次新建、改名、移动、解散、加入、移除或清空；无变化的重复加入不覆盖撤销记录。撤销恢复成员关系和操作前的位置，并正常自动保存，不修改原件或其他功能列表。撤销记录只在本次会话内保留；加载期间不可撤销。底部按钮或输入区域的 Ctrl+Z 触发，文本框保留自身撤销行为。

## 处理范围

勾选文件只处理勾选项；勾选软件文件夹包含其中的全部已收集引用及子分组。混选展开后按实际路径去重，保持文件夹与文件列表顺序。无选择时使用当前软件文件夹及子树，根目录对应全部输入；显示筛选不改变这个范围。空分组被选中时得到空输入，不能回退成处理全部文件。

转换继续计算实际输入的共同目标。范围提示区分所选文件夹、直接选中的文件和展开去重后的实际数量；空文件夹明确提示为空，图片/文档等混选没有共同目标时显示各类型数量并提示分开选择。软件分组节点不传给引擎；磁盘文件夹仍按现有转换限制反馈。切换软件文件夹、调整成员、选择或参数后旧计划失效，同路径集合也不能复用来自另一分组的迟到计划。图片合并 PDF 沿展开后的列表顺序，输出位置仍由操作参数决定。

## 保存与代码职责

- Core `Features/FileCollections` 保存文件夹、成员关系、快照及转交包，负责去重、树校验、展开和整理，不访问磁盘。
- `WorkspaceViewModel.Collections` 提供通用导航、范围、引用检查和保存状态，`WorkspaceViewModel.Undo` 管理单步快照；`FileInputView.Collections` 处理菜单、键盘、拖放等视图事件。目录选择和来源选择使用共用控件，`CollectionSourceSelection` 独立维护弹窗内跨目录勾选，所有页面复用 `FileCollectionDialogs`。
- Infrastructure `JsonFileCollectionStore` 为每个输入维护独立 JSON。位置为 `%LOCALAPPDATA%/FileAssistant/Collections/{staging,copy,conversion}.json`，只保存结构、引用、基础元数据和当前分组，不保存文件内容、选择或待执行任务。
- 保存合并 400 ms 写入临时文件后原子替换，关闭时补写；失败显示重试入口，关闭补写失败时保留窗口。恢复失效路径时保留引用并标记，可重新检查或移出。损坏数据先保留备份，其他版本数据暂停保存以防覆盖。
- 启动恢复完成前保持编辑锁定；转交或引用检查取消后，迟到结果不能改变后续导入的内容与加载状态。搜索的暂存区来源通过全局去重引用提供，结果列表不出现软件分组节点。输出、任务和转换引擎的职责继续分开。
