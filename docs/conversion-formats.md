# 本地转换支持表与限制

更新：2026-10-31。以下为本项目已接入的路线，不代表底层引擎的全部能力。运行验证和受阻项目见 [阶段交接](handoff-2026-10-31-format-next.md)。

## 支持路线

| 输入 | 输出 | 执行引擎与行为 |
| --- | --- | --- |
| DOC / DOCX / ODT / RTF / TXT | 这五种格式互转、PDF | LibreOffice；每个输入单独输出；TXT 为 UTF-8 |
| XLS / XLSX / ODS | 这三种格式互转、PDF、CSV、TSV | LibreOffice Calc；工作簿互转保留所有工作表，PDF 按打印区域与分页设置输出 |
| CSV / TSV | XLS / XLSX / ODS、PDF、CSV / TSV | LibreOffice Calc；显式编码、分隔符和公式导入设置；普通模式不显示同后缀 |
| PPT / PPTX / ODP | 三者互转、PDF | LibreOffice Impress；每份文件单独输出 |
| JPG / JPEG / PNG / WebP / BMP / GIF / TIFF / ICO / AVIF / HEIC / HEIF | PNG / JPG / WebP / BMP / TIFF / GIF / AVIF、合并 PDF | Magick.NET；格式筛选排除普通模式的同格式目标 |
| SVG | PNG / JPG / WebP | Magick.NET 的 SVG 解码器；仅自包含 SVG，拒绝外部资源和 XML 实体 |
| PNG / JPG / JPEG | ICO | Magick.NET；一个图标包含 16、24、32、48、64、128、256 像素版本 |
| GIF ↔ WebP | GIF / 动态 WebP | 保留帧顺序、画布、时长和循环；WebP 动画采用逐帧无损编码 |
| 多页 TIFF | 逐页图片、合并为多页 PDF | 默认全部页面；也可明确选择单页 |
| PDF | PNG / JPG / WebP / BMP / TIFF / GIF / AVIF | PDFium 按页输出，每页一个文件；72–600 DPI |
| 含有效文本的 PDF | UTF-8 TXT | PdfPig；按页序、文字块阅读顺序提取，保留换行，以换页符分隔页面 |
| MP3 / WAV / FLAC / M4A / AAC / OGG / Opus / WMA / AIFF / AIF | MP3 / WAV / FLAC / M4A / AAC / OGG | FFmpeg；选择一个音轨输出 |
| MP4 / MKV / MOV / WebM / AVI / WMV / M4V | MP4 / MKV / MOV / WebM；提取 MP3 / WAV / M4A / FLAC | FFmpeg；视频保留首个非封面视频流和所选音轨；提取音频时不输出视频 |

HEIC/HEIF、部分复杂 SVG 等历史解码输入的真实样本覆盖仍有限；不要把“能力表已接入”写成每种相机/编码变体均验证通过。

## 表格参数

- 编码：UTF-8（默认）或 GB18030。导入与导出使用所选编码；不猜测原文件编码。
- CSV 默认逗号，可改为分号或 Tab；TSV 固定 Tab。引号使用双引号，支持含分隔符、引号、换行的单元格。原 CSV 的 `sep=` 首行由 LibreOffice 按其规则解释。
- 数字解析固定英语区域规则，避免随系统区域变化；本轮不开放日期类型推断或逐列类型编辑。数值文本、前导零与日期应在转换后核对。
- 导出工作表 `0` 表示全部，`1…N` 指定表序号，包含隐藏表。每表一个文件，计划列出表名、序号及输出名称：`原名_表001_表名.csv`。无效表号明确拒绝；空表允许生成合法空 CSV，并有对应计划条目。
- 默认导出计算结果，可勾选导出公式。CSV/TSV 无法保存样式、图表、多表关系和跨表依赖。公式文本导回时需主动勾选“作为公式”；默认等号开头内容按文本导入。跨表公式单独导出后不再是自包含工作簿。
- XLS 的行列数及旧格式功能限制、LibreOffice 与 Excel 的函数差异仍存在。复杂公式、外链、数据连接和宏不保证等价；不运行宏，不自动更新外部文档链接。PDF 遵循工作簿的打印区域，不强制一表一页。

实现使用 [LibreOffice CSV 过滤参数](https://help.libreoffice.org/latest/en-US/text/shared/guide/csv_params.html)，区分导入数值检测与导出数值选项，明确工作表及公式开关。

## 演示、PDF 与图像

- 演示 PDF 是静态页面，不保留动画、转场、交互或嵌入音视频的播放。字体缺失会替换；特殊效果、复杂图表和旧 PPT 限制可能改变外观。须核对字体、图片、图表、页尺寸和分页；不能保证与 Microsoft Office 像素一致。
- PDF 文本提取不含 OCR。全部无有效文字时失败且不生成空 TXT；混合文本/扫描文件中，无文字的页有明确标记。PDF 内部文字编码和复杂多栏阅读顺序无法总是准确恢复；输出为文字，不是排版复刻。
- GIF/WebP 相互转换处理全部帧。GIF 是 256 色、二值透明、10 毫秒时长粒度；WebP 的半透明与细于该粒度的时长无法被 GIF 精确保留。GIF 转 WebP 的无损指图像编码，不恢复 GIF 已损失的颜色。
- TIFF 默认逐页输出；转 PDF 时按输入列表顺序，将 TIFF 的各页插入合并 PDF。其他动画转 PDF或静态格式，使用明确的帧号，默认 1。指定不存在的帧/页时失败。
- 图像缩放保持比例且不放大；图标会生成固定尺寸，非正方形补透明。JPG/BMP 不支持透明，铺白输出。
- WebP 动画使用 Magick 编码每一帧，并按 [WebP 容器规范](https://developers.google.com/speed/webp/docs/riff_container)写入完整画布，避免动画优化合并重复帧或裁掉透明边界。转换不承诺保留 EXIF、ICC、XMP 等全部元数据；输出图像使用 sRGB。
- 图片最多 10000 帧，展开画布合计不超过一亿像素；PDF 页面渲染也有像素限制。预览缓存最多 200 项且最多 256 MiB；转换始终读取原件，完全不依赖预览缓存。

## 音视频与同格式处理

- 普通转换菜单取当前范围内每个输入的真实目标交集，并排除同格式；压缩/兼容模式只显示实际可重新编码的同格式，例如 JPG → JPG、MP4 → MP4。文档和 PDF 不开放该模式。
- 三个预设：均衡保留尺寸和采样率、图片质量 90、视频 4000 kbps、音频 192 kbps；较小文件限制最长边 1280、图片质量 75、视频 1500 kbps、音频 128 kbps；兼容优先限制最长边 1920、图片质量 90、视频 4000 kbps、音频 192 kbps、采样率 48 kHz。参数可继续调整，重新编码不保证体积一定变小。
- 图像质量用于 JPG、静态 WebP 和 AVIF；最长边为 0 表示保留尺寸。动态图 WebP 使用无损编码，不显示无效的有损质量设置。
- 音轨序号从 1 开始；计划探测实际音轨数、编码和可用标签，显示选择结果。无音轨时提取失败；指定越界轨道失败。无音轨的视频仍可转视频。
- MP3 用 libmp3lame；WAV 为 16 位 PCM；FLAC 为无损；M4A/AAC 用 AAC；OGG 用固定质量 5 的 Vorbis。只为适用目标显示码率设置；有损源转无损不恢复音质。
- MP4/MKV/MOV 为 H.264（libopenh264）+ AAC，WebM 为 VP9 + Opus（固定 48 kHz）。支持最长边、视频码率、音频码率；其他适用目标的音频采样率可选择保留、22050、44100、48000 Hz。像素格式固定 yuv420p，奇数尺寸补齐偶数。
- 输出一个视频流和一个所选音轨；字幕、额外轨道、章节及原元数据不承诺保留。

## 计划、原件与失败

有选择时展开所选文件/软件文件夹，否则展开当前软件文件夹及子树；按真实路径去重。磁盘文件夹不作为可转换文件。文本文档、表格、演示、音频、视频分别成批；图片与 PDF 可共享适用图像目标。不支持项与无共同目标必须先提示，不能静默缩小批次。

任何参数、选择、分组或输入变化使旧计划失效；用户先看逐项计划，再点击开始。执行前后检查原件大小与修改时间。已有输出自动编号；计划后出现的新冲突逐项失败，绝不覆盖。先写临时文件，完成后原子提交；取消保留此前成功结果，失败和未完成项留在任务明细。清理失败给出临时路径。

## 安装、离线与许可证

所有处理在本机；基础引擎复用现有包，LibreOffice 在设置中由用户主动安装/修复，作为独立进程调用，不安装或借用系统 Office。没有新增运行时 NuGet 依赖或引擎下载。第三方保留各自许可证和声明；自有代码许可证尚未确定，未新增项目 LICENSE。版本、源码与分发边界见 [第三方声明](../third-party/README.md)。

离线验收命令：先在线准备并完成 `scripts/test.ps1` 与 `scripts/test.ps1 -Office`，正常断开网络后运行 `scripts/test.ps1 -Offline`、`scripts/test.ps1 -Office -Offline`。离线模式禁止构建/还原/下载，发现仍有联网接口会拒绝并明确标记未运行；真实转换测试每例创建全新路径、空预览缓存和独立 Office 配置。联网冷缓存通过不等于离线通过。

本阶段不含 OCR、PDF 转可编辑 Word/Excel、专业 RAW/CAD/3D 或压缩包转换。
