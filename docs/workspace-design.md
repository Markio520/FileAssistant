# 主工作区设计与验收

## 2026-10-30 第三步实现与交接

全局入口和页标题已改为“文件暂存区”。暂存区与“复制与整理”复用 `FileInputView`，各自保存独立输入；上方提供添加文件/文件夹、粘贴及功能转交，下方显示本次添加摘要并可查看逐项明细。暂存区的“用于功能”明确显示选中/全部数量；功能内的导入弹窗默认未选中，用户可显式全选。直接添加到功能不自动进入暂存区。文件夹按本身加入，不隐式展开。

继续复用公共主题和类型/外观选择框，新增动作使用原生菜单，选择和明细使用原生 ContentDialog / ListView。暂存区检查器仅保留文件信息；复制功能保留参数界面，执行按钮仍禁用。任务队列共用原有状态，添加文件不会生成执行任务。没有新增位图或设计依赖。

本轮观察到标准浅色空暂存区、新导航与输入按钮、原生文件选择器成功打开，以及搜索得到 9 个隔离测试文件。系统 PickerHost 未被窗口工具列为可操作目标，用户已手动取消弹窗；随后用户要求先保存并推送以换电脑继续。不能把入口显示或状态测试等同于所有交互已验收。

复核中发现 Pivot 会显示已折叠内容对应的“操作参数”标签，已改为从暂存区检查器移除此标签；最终补丁尚待重启应用后原生复验。新增文件读取与输入状态测试通过，最终统计及剩余验收步骤见[开发交接](handoff-2026-10-30.md)。本轮结论：代码与构建可交接，完整界面验收待继续。

## Direction contract

- THESIS：文件列表是主工作面，选中项与右侧详情同步；操作参数与底部队列留在同一个窗口内。
- OWN-WORLD：原生 Fluent 控件、冷灰底、白色工作面、青色选择与主操作；深色使用分层石墨灰与浅青强调。中文系统字体、细分隔线、克制圆角。
- STORY：先看到批次，再核对文件，随后配置参数；当前用带标签的示例呈现步骤，不能把示例当成真实导入和执行结果。
- FIRST VIEWPORT：默认约 1320×820 DIP，左栏 196 DIP，右栏 304 DIP，余下空间交给文件列表。顶部 28 DIP 标题与搜索框，表格约 64 DIP 行高。窗口收窄后导航缩为图标，右栏收至 280 DIP，长名称截断且可查看完整提示。
- FORM：用户已指定的桌面四区结构，遵循 Windows 原生操作习惯；未运行随机概念选择。识别特征是青色选中行与同色详情标记的即时联动。只使用控件自带反馈动画。
- FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
