# 主工作区设计与验收

## 2026-10-30 第三步实现与交接

全局入口和页标题已改为“文件暂存区”。暂存区与“复制与整理”复用 `FileInputView`，各自保存独立输入；上方提供添加文件/文件夹及功能转交，支持 Ctrl+V 粘贴，下方显示本次添加摘要并可查看逐项明细。用户已要求删除单独的“粘贴”按钮和空状态文件引用说明，内部引用规则不变。暂存区的“用于功能”明确显示选中/全部数量；功能内的导入弹窗默认未选中，用户可显式全选。直接添加到功能不自动进入暂存区。文件夹按本身加入，不隐式展开。

类型/外观选择复用公共 `SelectionDropDown`，类型按钮不再单独缩小宽度。搜索、暂存区和独立功能输入共用九类选项（所有、音频、压缩文件、文档、可执行文件、文件夹、图片、视频、仅文件）与 Core 过滤规则。添加、用于功能、界面示例改用公共 `ActionDropDown`，按钮和弹层共用 `SelectionControls.xaml` 的样式、间距及主题配色，弹层下方居中；动作保持原生菜单语义。选择和明细使用原生 ContentDialog / ListView，并明确采用当前页面主题。暂存区检查器仅保留文件信息；复制功能保留参数界面，执行按钮仍禁用。任务队列共用原有状态，添加文件不会生成执行任务。没有新增位图或设计依赖。

用户进一步指定搜索页类型菜单为统一尺寸标准：按钮/菜单行最小高度 32 DIP、项内边距 12,6、外边距 0,1，正常字体下相邻行间距 34 DIP，弹层内边距 4 DIP。绿色竖条只标记已选项，未选项悬停只显示背景；动作菜单没有持久选中值，悬停及键盘焦点不显示竖条或黑色焦点框。这些规则集中维护于公共样式，并已加入项目约定供后续复用。

续接后已完成路径粘贴、文件剪贴板粘贴、重复/失效/不支持反馈、选中/全部转交、功能独立输入、默认未选的导入弹窗、追加去重、双向显式交换、独立移出/清空、列表 Ctrl+A / Delete 和目录搜索结果加入。系统 PickerHost 及跨应用拖放由用户补验，用户确认选择两个文件、选择文件夹、从资源管理器拖入、复制文件后列表 Ctrl+V 四项均成功，随后从应用列表确认了对应引用。11 个隔离样本文件的内容哈希均未改变。

原生复验已确认暂存区没有“操作参数”标签，并修复了选中文件后仍显示选择提示的问题。标准/紧凑、浅/深色和长路径详情已检查，紧凑浅色明细正常；搜索列宽、排序、信息栏和命名条件跨重启恢复通过，文件列表重启后为空。用户补充下拉尺寸及悬停要求后，最新公共样式的原生检查确认：类型菜单已选“所有”保留竖条，悬停“音频”只有背景；深色外观选择器也保持已选“深色”的竖条，悬停其他项不加竖条。动作菜单浅/深色悬停及键盘高亮均无绿条或黑框，方向键和 Enter 可正常执行“从搜索结果添加”。按钮/行高和间距已共用上述尺寸。深色页面的导入/明细弹窗已补充主题继承，但该弹窗补丁仍待原生复验。最终统计见[开发交接](handoff-2026-10-30.md)。

系统入口参考 [Windows 文件选择器](https://learn.microsoft.com/windows/apps/develop/files/using-file-folder-pickers)、[拖放](https://learn.microsoft.com/windows/apps/develop/data/drag-and-drop) 和 [复制粘贴](https://learn.microsoft.com/windows/apps/develop/communication/copy-and-paste)。

## 真实预览与常用转换（2026-10-30 已接入）

用户授权接入 Magick.NET、FFmpeg、PDFium/PDFiumCore 和 PdfPig。公共预览面板现可显示图片、视频第一帧、PDF 首页及部分文本；切换选择时取消旧请求并隔离过期结果，失败保留图标和提示。格式转换使用独立输入并复用输入控件，支持 PNG/JPEG/WebP/BMP、图片合并 PDF、PDF 逐页导出图片；执行前展示实际文件计划，执行时重新核对原件状态，已有同名文件编号保留。

引擎代码集中在 `Infrastructure/Engines`，Core 提供公共预览/转换/下载契约；下载清单与调用示例见 [engines/README.md](../engines/README.md)。FFmpeg 输入协议受限于本地文件，处理不调用在线转换服务。已通过真实引擎样本、页序颜色、透明铺白、中文路径、原件哈希、执行前冲突、取消部分完成及异常输入测试。常用引擎随软件交付，专业包待后续逐项接入。用户补验新路径冷缓存的图片/视频/PDF 预览及 WebP/PDF 转换均成功；用户明确未断网，物理断网验收保留为未完成。
## 引擎管理与文件输出区（2026-10-30 已接入首版）

设置显示真实引擎检查、版本、能力及本机位置，支持用户手动下载/修复视频组件、进度、取消和重试。下载固定清单 SHA-256 校验后才解压激活，失败和取消保留原安装，下载结束不自动处理文件；专业扩展清单、版本卸载及更新历史尚未开放。

文件输出区位于暂存区旁，收集执行结果中的实际成功文件，支持一对多/多对一，按任务与路径筛选、预览、打开、定位、复制路径及显式交给暂存区/其他功能。清空记录保留真实文件，失败和取消项目在任务队列明细中查看。输入、任务和输出目前均只保留本次运行记录。

## Direction contract

- THESIS：文件列表是主工作面，选中项与右侧详情同步；操作参数与底部队列留在同一个窗口内。
- OWN-WORLD：原生 Fluent 控件、冷灰底、白色工作面、青色选择与主操作；深色使用分层石墨灰与浅青强调。中文系统字体、细分隔线、克制圆角。
- STORY：先看到批次，再核对文件，随后配置参数；当前用带标签的示例呈现步骤，不能把示例当成真实导入和执行结果。
- FIRST VIEWPORT：默认约 1320×820 DIP，左栏 196 DIP，输入页右栏默认 304 DIP，余下空间交给文件列表。顶部 28 DIP 标题与搜索框，表格约 64 DIP 行高。窗口收窄后导航缩为图标，右栏按可用空间限制宽度，可拖动或收起；长名称截断且可查看完整提示，表格可横向滚动。
- FORM：用户已指定的桌面四区结构，遵循 Windows 原生操作习惯；未运行随机概念选择。识别特征是青色选中行与同色详情标记的即时联动。只使用控件自带反馈动画。
- FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
