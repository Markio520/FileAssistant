## Direction contract

- THESIS：文件列表是主工作面，选中项与右侧详情同步；操作参数与底部队列留在同一个窗口内。
- OWN-WORLD：原生 Fluent 控件、冷灰底、白色工作面、青色选择与主操作；深色使用分层石墨灰与浅青强调。中文系统字体、细分隔线、克制圆角。
- STORY：先看到批次，再核对文件，随后配置参数；当前用带标签的示例呈现步骤，不能把示例当成真实导入和执行结果。
- FIRST VIEWPORT：默认约 1320×820 DIP，左栏 196 DIP，右栏 304 DIP，余下空间交给文件列表。顶部 28 DIP 标题与搜索框，表格约 64 DIP 行高。窗口收窄后导航缩为图标，右栏收至 280 DIP，长名称截断且可查看完整提示。
- FORM：用户已指定的桌面四区结构，遵循 Windows 原生操作习惯；未运行随机概念选择。识别特征是青色选中行与同色详情标记的即时联动。只使用控件自带反馈动画。
- FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 交互范围

- 已实现的界面交互：示例载入、列表多选、当前列表搜索和类型过滤、移出选中项、清空、空状态、无匹配状态、可取消加载、可恢复错误示例、详情联动、参数切换、浅深色/系统主题、队列展开及明确标注的进度示例。
- 后续接入：文件选择器、拖放读取、图片/PDF/音视频真实预览、真实目标目录、复制计划、冲突检测与后台执行。当前相关按钮明确禁用。
- 搜索仅针对当前内存列表，不代表已完成规划中的磁盘搜索。
- 所有示例目录、名称、大小、时间和进度均为构造数据。

## 验收记录

2026-10-29，Windows 11 x64：

- Debug / x64 解决方案构建通过，零警告、零错误；非打包主窗口可运行。
- 原生窗口检查覆盖浅色/深色、空列表、长文件名选中、详情联动、复制参数和任务进度示例；检查了约 1320×820 与 960×640 的窗口，截图存于 `artifacts/ui-review/`。截图不包含窗口的不可见缩放边框，像素尺寸会略小于 AppWindow 外框尺寸。

- 原生键盘检查：列表 Ctrl+A 选中 8 项；搜索「产品」得到 1/8 项，搜索框 Ctrl+A / Delete 清空关键词后恢复 8/8 项且批次未被移除。两条列表快捷键均显式限定到 FileList。列表 Delete 的独立键盘回归因桌面焦点切换未完成，不将其记为通过；移出/清空逻辑已通过下述状态检查。
- 使用已安装的 MVVM Toolkit 对实际 ViewModel 源码执行 18 项临时检查，全部通过：初始空状态、载入、大小写搜索、路径搜索、类型筛选、无匹配、恢复筛选、清除过期选择、移出筛选结果、取消保留原批次、加载中清空避免回填、错误覆盖取消、错误恢复、进度示例标识和大小格式边界。检查入口为 `artifacts/workspace-state-check/WorkspaceStateCheck.csproj`，未新增业务测试依赖。
- 独立复核的两项问题（紧凑状态挂载位置、键盘快捷键范围）已修正，修复复核结论为 `ship`：两项均已解决。该结论仅针对这两项修复，不替代完整产品、发布或真实文件操作验收。
